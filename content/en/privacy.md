**ai.ondralinek.cz** is a static personal website operated by Ondra Linek.

## What this site does not do

- **No cookies** — this site sets no cookies and uses no local storage for tracking.
- **No third-party scripts or fonts** — every asset is self-hosted on this origin.
- **No analytics or advertising trackers** — your visit is not profiled or shared with third parties.

## Server access logs

The web server (nginx) records standard HTTP access and error logs (IP address, timestamp, requested path, status code, and user agent) strictly for operational reliability, abuse prevention, and security monitoring. Logs are rotated automatically and are not combined with other data sources or shared externally.
