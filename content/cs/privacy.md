**ai.ondralinek.cz** je statický osobní web provozovaný Ondrou Linkem.

## Co tento web nedělá

- **Žádné cookies** — web neukládá žádné cookies ani nepoužívá lokální úložiště ke sledování.
- **Žádné skripty ani fonty třetích stran** — veškeré soubory jsou servírovány přímo z této domény.
- **Žádná analytika ani reklamní trackery** — návštěva není profilována ani předávána třetím stranám.

## Logy webového serveru

Webový server (nginx) ukládá standardní přístupové a chybové logy HTTP (IP adresa, čas, požadovaná cesta, stavový kód a User-Agent) výhradně pro zajištění spolehlivosti provozu, ochranu před zneužitím a bezpečnostní dohled. Logy se automaticky rotují, nepropojují se s jinými zdroji a nikam se nepředávají.
